# Portal Core Components

Components in this directory belong exclusively to **Portal Core** and are shared across all pages:

- **Sidebar**: Database-driven responsive navigation.
- **Topbar**: Top navigation, notifications, search, user dropdown.
- **Footer**: Centralized footer with school copyright.
- **MaintenanceModal**: Global maintenance view when systems are under maintenance.
- **InactivityModal**: Warning modal when session inactivity timeout is approaching.
- **AnnouncementBanner**: Global and system-level announcement components.

**RULE**: System modules must NEVER duplicate or reimplement these core layout elements.
